# Atr Do'koni — Telegram Mini App

Next.js + Supabase. Telegram ichida ochiladigan atr do'koni.

- `/` — do'kon (katalog, mahsulot, savat, buyurtma)
- `/admin` — mahsulotlar va buyurtmalarni boshqarish (parol bilan)

## Sozlash
1. Supabase loyihasi (jadvallar: products, orders, order_items, app_settings) tayyor bo'lishi kerak.
2. Vercel'ga ulang. Ixtiyoriy muhit o'zgaruvchilari: `BOT_TOKEN`, `ADMIN_CHAT_ID` (yangi buyurtma haqida Telegram xabari).
3. BotFather'da botga Mini App havolasini (Vercel manzili) ulang.
